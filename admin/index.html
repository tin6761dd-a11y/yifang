益芳官網編輯

登入後就能改價格、文字和照片

加到手機桌面，以後一點就能改

iPhone / iPad（請用 Safari 打開本頁）
  1. 點下方的「分享」按鈕（方框加上向上箭頭）。
  2. 向下滑，選擇「加入主畫面」。
  3. 名稱確認是「益芳官網編輯」後，按「新增」。
Android（請用 Chrome 打開本頁）
  1. 點右上角「⋮」選單。
  2. 選擇「加到主畫面」或「安裝應用程式」。
  3. 按「新增」或「安裝」。
電腦（書籤或安裝）
  1. 在 Chrome 或 Edge，如果網址列右側出現安裝圖示，點一下即可裝成小應用程式。
  2. 也可以把本頁加入書籤，之後一鍵開啟。

第一次貼上權杖並登入後，權杖會留在這個裝置的瀏覽器裡。下次從桌面開啟會直接進入編輯畫面。

第一次使用：建立專用權杖

請先用 tin6761dd-a11y 這個 GitHub 帳號登入，再依下面步驟做一組「只給這個官網用」的權杖。

  1. 打開這個頁面：https://github.com/settings/personal-access-tokens/new（請用瀏覽器開啟，不要用應用程式內建瀏覽器）。
  2. Token name（權杖名稱）：填「益芳官網編輯」。
  3. Expiration（到期日）：建議選 90 days（90 天）。到期後再重新建立一次即可。
  4. Resource owner（資源擁有者）：選 tin6761dd-a11y。
  5. Repository access（儲存庫存取）：選 Only select repositories（只選特定儲存庫）。
  6. 在 Selected repositories 裡，只勾選 yifang，不要選其他專案。
  7. 在 Permissions → Repository permissions（儲存庫權限）中，找到 Contents（內容），設成 Read and write（讀寫）。其他項目都維持 No access 即可。
  8. 按頁面最下方的 Generate token（產生權杖）。
  9. 立刻複製那一串以 github_pat_ 開頭的文字（GitHub 只會顯示一次），貼到下面欄位。

這組權杖等於能改官網的鑰匙。請不要傳給別人，也不要貼在網址、訊息或電子郵件裡。權杖只會保存在這個裝置，不會存進官網或 GitHub 檔案。

店家資料

維

請填 1～2 個字，例如「維」。儲存時會同時更新分頁小圖示（favicon）。

電話

可填多組電話。第一組會作為主要聯絡電話（搜尋資料也會用這組）。名稱可填「客服」或「手機」，也可以留空。

進階：地圖與搜尋資料

選單與按鈕文字

這些文字會出現在官網上部選單、首頁按鈕和各區塊標題。改這裡就不用改程式。

公告與付款方式

頂部公告條可以開關。付款說明會顯示在全新封口機、中古機專區、零件專區和聯絡我們。

線上客服（Tawk.to）

填入 Property ID 與 Widget ID 後，官網「免費客服諮詢」面板最上方會出現線上文字客服入口，商品卡也會顯示「詢問這個商品」按鈕。Tawk 自己的圓形圖示會隱藏，避免出現兩個客服按鈕。下方「客服按鈕名稱」可自行修改。還沒申請前可先留空。回覆顧客請點上方「客服聊天室」，或下載 tawk.to App 用手機回覆。

客服諮詢管道

會出現在「客服諮詢」區塊和右下角浮動按鈕。LINE 若還沒有連結或 ID，請先留空或關閉顯示，之後有了再填。

服務項目

全新封口機

這裡的每一筆都是單一一台商品。展示機可在「標籤」填例如「展示機 9.99成新．保固一年」。勾選「隱藏」後就不會出現在官網。若已設定線上客服，商品卡會出現「詢問這個商品」按鈕。可用「分類」把商品改放到中古機或零件專區。

中古機分組（封口機、果糖機等）

機型一樣、售價差不多的可以放在同一組，只寫大概價格。機器賣掉了也不必立刻改網站。名稱請沿用「微電腦」「機械式」「碼錶機械式」等專有名詞，不要自行改寫。可用「分類」改子分類（官網篩選按鈕會跟著變），或把這一組改放到全新封口機、零件專區。

零件專區

零件可依「封口機零件」或「果糖機零件」分類，也能自己改分類名稱。勾選「隱藏」後就不會出現在官網。可用「分類」改子分類（官網篩選按鈕會跟著變），或把零件改放到全新封口機、中古機專區。

常見問題（選填）

沒有內容時，官網不會顯示這個區塊。

加到手機桌面

用 Safari（iPhone）或 Chrome（Android）打開本頁後，「分享／選單」裡選擇「加入主畫面」或「安裝應用程式」，名稱是「益芳官網編輯」。之後點桌面圖示就會直接進入編輯畫面。
